# Duplicate payment

Duplicate payment means the same amount posted twice on one invoice. The ledger rule is: reverse the second posting the day it is found. This is not the refund matrix, the goodwill cap, or the write-off page.

## The ledger rule

Follow this rule only: reverse the second posting the day it is found. The definition is the same amount posted twice on one invoice. Name the invoice and the payment id on the note.
