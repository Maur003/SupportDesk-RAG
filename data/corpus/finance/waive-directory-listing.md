# Waiving the directory listing

The ledger name for this line is directory listing, billed at 3 dollars. Finance may waive or cap it under this rule: when the listing was added in error. Frontline staff cannot drop it on the call.

## Who may change the line

The finance rule is when the listing was added in error. That rule is not the rule on the household page, which only states 3 dollars. A waiver note names the invoice, the line, and the rule that was used. Staff write the clock time and the ticket id on the note for waive Directory listing (when the listing was added in error). They compare waive Directory listing (when the listing was added in error) with the neighboring page before they quote it. The neighboring page uses the same steps and a different figure. Quoting the neighboring figure on a waive Directory listing (when the listing was added in error) note is a misread. The note stays on the account for 24 months. A later reader looks for waive Directory listing (when the listing was added in error) and does not copy the note onto another page.
