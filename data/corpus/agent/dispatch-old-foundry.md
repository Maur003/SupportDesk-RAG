# Old Foundry dispatch

For banner OF-09, dispatch Foundry Night when optical loss stays above 4.4 dB for 60 minutes. Do not dispatch Foundry Night for a single apartment under that line. The 4.4 dB line is Old Foundry only.

## Recognizing the banner

Banner OF-09 maps to Old Foundry. A ticket that names a different banner is a different spur and a different crew. Write OF-09, the dB reading, and the clock time before paging Foundry Night. Staff write the clock time and the ticket id on the note for Old Foundry OF-09 at 4.4 dB. They compare Old Foundry OF-09 at 4.4 dB with the neighboring page before they quote it.
