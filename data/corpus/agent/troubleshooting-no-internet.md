# No internet troubleshooting

Agents use this sequence for a residential fiber customer who reports no connection. Skipping ahead is allowed only when the outage banner is already open.

1. Confirm the account and the service address before any reboot instruction.
2. Check the outage banner. If it is open, stop and quote the banner id.
3. Ask whether the optical light is green, amber, or red.
4. A green light means the plant is up and the agent moves to in-home checks.
5. An amber light means the gateway is starting. The agent waits 5 minutes and asks again.
6. A red light after 10 minutes is a plant symptom when no banner is open.
7. Ask the customer to unplug the gateway for 60 seconds.
8. Ask them to plug it into the original power supply.
9. A third-party power supply is noted and is not a reason to refuse help.
10. If the light returns to green, ask for an in-app speed test on a wired device.
11. If the wired test meets 80 percent of the plan, the ticket is in-home.
12. If it does not, open a plant ticket with the test id.
13. Do not schedule a technician until the plant ticket is accepted.
14. Tell the customer the ticket number before the call ends.
15. If several households on the same street report a red light, raise the ticket using the escalation matrix.
16. Single-household red lights stay with the local network desk.
17. Record the gateway serial number from the sticker, not from memory.
18. Do not ask the customer to open the gateway case.
19. Do not promise a same-day visit.
20. If the customer has mobile service on the same account, confirm that mobile data still works.
21. Mobile working and fiber down is still a fiber ticket, not a mobile ticket.
22. Offer the outage credit path only after the banner duration is known.
23. Agents apply credits only inside the agent outage credit rule.
24. Close the troubleshooting notes with the light color and the test id.
