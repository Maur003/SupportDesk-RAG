# Escalation matrix

Severity 1 outages are escalated to the network duty manager within 15 minutes. A severity 1 event is a full loss of service for 50 or more households, or a full loss of mobile data in a city sector. Severity 2 events are owned by the local network desk and reviewed every 30 minutes. Agents do not page the duty manager for a single-household optical light. The ticket must include the outage banner id when one exists.
