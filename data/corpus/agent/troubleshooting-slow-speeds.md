# Slow speed troubleshooting

Agents ask the customer to run the in-app speed test on a wired connection before opening a network ticket. If the wired result is at least 80 percent of the plan speed, the agent treats the issue as in-home and walks through gateway placement. If the wired result is below 80 percent, the agent opens a plant ticket and records the test id. Agents do not promise a technician visit until the plant ticket is accepted.
