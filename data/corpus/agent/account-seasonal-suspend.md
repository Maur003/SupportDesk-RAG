# Seasonal suspend

Seasonal suspend means a suspend of wireline service for a vacant month. The rule on this page is: at most 2 months, and the number is kept. A neighboring account page uses a different rule.

## The rule

Apply only this rule: at most 2 months, and the number is kept. The definition is a suspend of wireline service for a vacant month. Write the ticket note with the page name so a later reader does not apply a neighboring rule.
