# Cedar Ridge dispatch

For banner CR-03, dispatch Ridge Night when optical loss stays above 2.5 dB for 30 minutes. Do not dispatch Ridge Night for a single apartment under that line. The 2.5 dB line is Cedar Ridge only.

## Recognizing the banner

Banner CR-03 maps to Cedar Ridge. A ticket that names a different banner is a different spur and a different crew. Write CR-03, the dB reading, and the clock time before paging Ridge Night. Staff write the clock time and the ticket id on the note for Cedar Ridge CR-03 at 2.5 dB. They compare Cedar Ridge CR-03 at 2.5 dB with the neighboring page before they quote it. The neighboring page uses the same steps and a different figure. Quoting the neighboring figure on a Cedar Ridge CR-03 at 2.5 dB note is a misread. The note stays on the account for 24 months.
