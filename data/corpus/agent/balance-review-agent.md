# What frontline staff may say about a balance

Frontline staff do not erase a balance. They open a billing ticket and stop. The dollar line and the desk code are on the finance page, which is not read aloud.

## What an agent may say

Tell the caller the ticket number. Do not quote a threshold, a number of days, or a desk code. Those live on the finance write-off page. Staff write the clock time and the ticket id on the note for agent balance handoff. They compare agent balance handoff with the neighboring page before they quote it. The neighboring page uses the same steps and a different figure. Quoting the neighboring figure on a agent balance handoff note is a misread. The note stays on the account for 24 months.
