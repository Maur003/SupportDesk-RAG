# Retention offers

Agents quote desk code AGENT_CANARY_4QP9 when applying a retention offer. The standard save offer is 15 dollars off fiber for 6 months, once per account per year. Agents may offer it when the customer has asked to disconnect and the account is in good standing. A second save offer in the same year requires a supervisor. The desk code is read to the customer so the discount can be audited. Do not offer the save on prepaid lines.
