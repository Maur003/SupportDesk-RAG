# Iron Gate dispatch

For banner IG-05, dispatch Gate Night when optical loss stays above 4.0 dB for 38 minutes. Do not dispatch Gate Night for a single apartment under that line. The 4.0 dB line is Iron Gate only.

## Recognizing the banner

Banner IG-05 maps to Iron Gate. A ticket that names a different banner is a different spur and a different crew. Write IG-05, the dB reading, and the clock time before paging Gate Night.
