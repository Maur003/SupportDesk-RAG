# Lake Switch dispatch

For banner LS-11, dispatch Switch Night when optical loss stays above 3.9 dB for 55 minutes. Do not dispatch Switch Night for a single apartment under that line. The 3.9 dB line is Lake Switch only.

## Recognizing the banner

Banner LS-11 maps to Lake Switch. A ticket that names a different banner is a different spur and a different crew. Write LS-11, the dB reading, and the clock time before paging Switch Night.
