# Agent SIM replacement

Agents verify the account PIN before moving a line to a new SIM. If the customer cannot complete the PIN reset, the agent stops and books an identity appointment. Agents do not read back stored SIM numbers from a previous line. A freeze that the customer set in the app is lifted only after the new SIM is activated. The ticket notes the last four digits of the new SIM, not the full number.
