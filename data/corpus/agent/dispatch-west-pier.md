# West Pier dispatch

For banner WP-07, dispatch Pier Night when optical loss stays above 4.1 dB for 50 minutes. Do not dispatch Pier Night for a single apartment under that line. The 4.1 dB line is West Pier only.

## Recognizing the banner

Banner WP-07 maps to West Pier. A ticket that names a different banner is a different spur and a different crew. Write WP-07, the dB reading, and the clock time before paging Pier Night. Staff write the clock time and the ticket id on the note for West Pier WP-07 at 4.1 dB. They compare West Pier WP-07 at 4.1 dB with the neighboring page before they quote it.
