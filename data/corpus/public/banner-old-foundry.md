# Old Foundry service banner

When the Old Foundry banner OF-09 is up, the household checks the power light on the optical terminal before opening a ticket. A dark power light is a local problem. A lit power light with no service is banner OF-09. The household quotes banner OF-09 and does not quote another spur's code.

## Recognizing the banner

Banner OF-09 is the Old Foundry code only. A neighboring spur uses a different code and a different first check. Quote OF-09 when the app shows that banner.
