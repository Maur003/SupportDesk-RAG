# Installation appointments

Standard installation is 0 dollars when the customer is home for a two-hour window. The technician waits 15 minutes past the window start before marking the customer as missed. A missed window is rescheduled, and the next visit is 50 dollars if the customer misses it again. The customer can change the window in the app until 8 hours before the start. Installation does not include inside wiring beyond the optical terminal.
