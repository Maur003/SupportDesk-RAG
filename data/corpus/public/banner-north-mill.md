# North Mill service banner

When the North Mill banner NM-14 is up, the household checks the power light on the optical terminal before opening a ticket. A dark power light is a local problem. A lit power light with no service is banner NM-14. The household quotes banner NM-14 and does not quote another spur's code.

## Recognizing the banner

Banner NM-14 is the North Mill code only. A neighboring spur uses a different code and a different first check. Quote NM-14 when the app shows that banner. Do not quote a code from a street outside North Mill. Staff write the clock time and the ticket id on the note for North Mill banner NM-14.
