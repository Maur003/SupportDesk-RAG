# Network status codes

Code OL-GREEN means the optical link is up. Code OL-RED means the optical link is down. Code BANNER-OPEN means the app is showing a neighborhood outage. Customers can quote these codes in chat. Agents record the code on the ticket. These codes do not include approval limits.
