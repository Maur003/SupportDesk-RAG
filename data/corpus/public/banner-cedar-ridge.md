# Cedar Ridge service banner

When the Cedar Ridge banner CR-03 is up, the household checks the power light on the optical terminal before opening a ticket. A dark power light is a local problem. A lit power light with no service is banner CR-03. The household quotes banner CR-03 and does not quote another spur's code.

## Recognizing the banner

Banner CR-03 is the Cedar Ridge code only. A neighboring spur uses a different code and a different first check. Quote CR-03 when the app shows that banner. Do not quote a code from a street outside Cedar Ridge. Staff write the clock time and the ticket id on the note for Cedar Ridge banner CR-03.
