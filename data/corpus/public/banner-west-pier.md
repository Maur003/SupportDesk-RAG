# West Pier service banner

When the West Pier banner WP-07 is up, the household checks the power light on the optical terminal before opening a ticket. A dark power light is a local problem. A lit power light with no service is banner WP-07. The household quotes banner WP-07 and does not quote another spur's code.

## Recognizing the banner

Banner WP-07 is the West Pier code only. A neighboring spur uses a different code and a different first check. Quote WP-07 when the app shows that banner. Do not quote a code from a street outside West Pier. Staff write the clock time and the ticket id on the note for West Pier banner WP-07. They compare West Pier banner WP-07 with the neighboring page before they quote it. The neighboring page uses the same steps and a different figure.
