# East Yard service banner

When the East Yard banner EY-22 is up, the household checks the power light on the optical terminal before opening a ticket. A dark power light is a local problem. A lit power light with no service is banner EY-22. The household quotes banner EY-22 and does not quote another spur's code.

## Recognizing the banner

Banner EY-22 is the East Yard code only. A neighboring spur uses a different code and a different first check. Quote EY-22 when the app shows that banner. Do not quote a code from a street outside East Yard. Staff write the clock time and the ticket id on the note for East Yard banner EY-22.
